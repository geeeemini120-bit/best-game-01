VOIDHARVEST — a twin-stick arena shooter. Pilot a harvester drone through a dying nebula, blast the void-spawn, collect stardust to raise your combo, and pick 1 of 3 upgrades between waves. Five enemy types, escalating waves, synth sound, and a best score that persists in your browser.

## Run it
node serve.ts
Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, aim with the mouse, hold click (or Space) to fire. P pauses, M mutes, 1/2/3 pick an upgrade.
